# 深色原生标题栏设计

## 目标

让 WPF 配置编辑器的原生 Windows 标题栏使用深色外观，使其与现有深蓝色主界面协调，同时保留系统绘制的最小化、最大化和关闭按钮，以及现有拖动、双击最大化和窗口缩放行为。

## 范围

- 仅修改 `AMacQGuiEditor.ps1`。
- 不修改窗口布局、窗口样式、应用内配色资源、动画或按钮样式。
- 不自定义标题栏，也不替换原生窗口控制按钮。

## 实现

1. 新增一个 PowerShell 函数，在运行时定义并调用 `DwmSetWindowAttribute`。
2. 函数从 WPF 窗口句柄取得原生 HWND，并尝试使用 Windows 的沉浸式深色模式 DWM 属性。
3. 为系统版本兼容，依次尝试属性 `20`（新版本 Windows）与 `19`（较早支持版本）。
4. DWM 调用失败或系统不支持时捕获异常并静默返回，继续使用系统默认标题栏，不能影响主窗口启动。
5. 在 XAML 创建完成后、`ShowDialog()` 前调用该函数。

## 行为

- 支持 Windows 深色标题栏的环境：标题栏采用系统深色外观，原生控制按钮继续可用。
- 不支持的环境：窗口维持系统默认标题栏，其他功能不受影响。

## 验证

- 对 PowerShell 脚本进行语法解析，确保没有解析错误。
- 手动启动 `AMacQGuiEditor.ps1`，检查标题栏为深色，且最小化、最大化、关闭、拖动和缩放均正常。
