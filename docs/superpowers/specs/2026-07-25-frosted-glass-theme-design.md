# AMacQ 浏览器版磨砂玻璃主题设计

**日期：** 2026-07-25  
**状态：** 待用户审阅

## 目标

将离线浏览器版配置编辑器的现有深蓝紫实色主题改为深蓝紫磨砂玻璃风格，同时不改变页面结构、JavaScript 编辑逻辑、文件保存方式或响应式布局。

## 视觉方案

- 页面使用多层蓝紫渐变光晕作为背景。
- 左侧栏、主内容区、设置区和底部操作栏使用半透明深色背景、柔和描边和 `backdrop-filter: blur(...)`。
- 输入框、下拉框和枪械列表使用更深一层的半透明玻璃表面，保证文本对比度与可读性。
- 保留青蓝至靛紫的强调色：当前枪械与“应用”按钮继续使用渐变，但降低视觉冲突。
- 使用透明白蓝边框及柔和阴影分隔玻璃层级。
- 扫描线覆盖层降低不透明度，避免干扰磨砂效果。

## 兼容性与降级

- 使用 `@supports (backdrop-filter: blur(1px))` 应用真实背景模糊。
- 不支持该特性的浏览器保留半透明深色背景、边框和阴影，所有控件仍可读、可操作。
- 保持现有 `prefers-reduced-motion` 规则；不引入额外动画或外部依赖。

## 修改范围

- 修改 `web/styles.css`。
- 在现有 Pester 网页入口测试中增加主题关键样式断言。
- 不修改 `web/index.html`、`web/app.js`、WPF 文件或 `.vbs` 启动器。

## 验证

- Pester 断言确认 CSS 包含半透明玻璃颜色、`backdrop-filter`、`@supports` 降级规则和降低后的扫描线透明度。
- 运行现有 Node 浏览器逻辑测试和 Pester 回归测试。
- 手工双击 `web/index.html`，检查宽屏和窄屏下文字、输入控件和主操作按钮仍有足够对比度。
