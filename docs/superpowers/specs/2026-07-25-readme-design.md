# README 设计

## 目标

为 AMacQ 配置编辑器创建面向中文普通用户的简明项目说明，帮助用户了解用途、运行条件与操作步骤。

## 内容

README 将包含：

1. 项目简介，明确仅编辑用户主动选择的本地 Lua 配置文件，不与游戏进程交互。
2. 功能列表：选择两份配置文件、发现枪械、编辑按键和灵敏度、编辑全局选项、保留编码并原子保存。
3. Windows、PowerShell 与 WPF 运行环境说明。
4. 通过 VBS 启动器和直接运行 PowerShell 脚本两种启动方式。
5. 从选择配置文件到应用保存的操作步骤。
6. 根目录主要文件的简短说明。
7. 数值格式、备份配置及本地操作边界等注意事项。

## 不包含内容

不加入未经验证的兼容性承诺、下载链接、许可证、贡献流程、截图或项目内部设计文档说明。
