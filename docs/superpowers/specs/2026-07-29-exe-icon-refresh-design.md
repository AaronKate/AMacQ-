# EXE 图标更新设计

**日期：** 2026-07-29  
**状态：** 已确认，待实施

## 目标

使用用户提供的 PNG 更新 AMacQ 配置编辑器的应用图标，并确保四个角区域透明，使其在 Windows 标题栏、任务栏和 EXE 文件资源管理器视图中以圆角图标显示。

## 方案

- 使用用户提供的 `87c0b374-0033-4f8c-8353-99b11c1507ea.png` 作为唯一图标输入。
- 通过现有 `tools/Convert-IconSource.ps1` 等比缩放至 256×256 并应用圆角透明蒙版，输出 `assets/AMacQ-source.png`。
- 通过现有 `tools/Convert-Icon.ps1` 生成包含 16、20、24、32、40、48、64、128、256 像素位图层的 32 位 ARGB `assets/AMacQ.ico`。
- `Build-Release.ps1` 继续将该 ICO 传给 ps2exe，无需修改打包或运行时图标加载逻辑。

## 验证

- 检查处理后的 PNG 为 256×256、32 位 ARGB，四个角的 alpha 为 0。
- 运行图标资源和边缘透明处理测试，确认 ICO 可读取并包含全部要求的尺寸。
- 运行发布脚本的静态测试，确认 EXE 打包链路仍使用 `assets/AMacQ.ico`。

## 不在范围内

- 不修改应用界面、业务逻辑、EXE 输出路径或打包工具配置。
- 不改变图标主体图案或颜色，仅进行缩放与四角透明处理。
