# 枪械界面文字统一设计

## 目标

将界面中面向用户的“武器”术语统一为“枪械”，并移除右侧冗余的“武器设置”辅助标题。

## 文字调整

- 左侧列表分组标题：`武器` 改为 `枪械`。
- 右侧顶部辅助标题 `武器设置` 完整删除。
- 右侧当前选择标题从 `武器：<名称>` 改为 `枪械：<名称>`。
- 无选择提示从 `请选择武器` 改为 `请选择枪械`。

## 实现边界

仅修改 `AMacQGuiEditor.ps1` 中的显示字符串及其初始化／加载重置文本。保留内部变量名、函数名、Lua 文件格式、武器数据读取、选择处理和保存逻辑。

## 验证

- 左侧标题显示“枪械”。
- 右侧顶部不显示“武器设置”。
- 选择 MP5 时右侧显示“枪械：MP5”。
- 未加载或加载失败时显示“请选择枪械”。
