# 左侧枪械列表搜索设计

## 目标

在左侧栏的“枪械”标题下方添加搜索输入框，方便从已加载的枪械列表中快速定位目标项目。

## 界面

- 搜索框位于“枪械”标题与枪械列表之间，提示文字为“搜索枪械”。
- 搜索框使用现有侧栏控件的白底、浅灰边框与圆角视觉语言。
- 枪械列表仍占用侧栏的剩余高度，可随窗口大小变化。

## 交互与数据流

- 每次输入变化时，按不区分大小写的包含匹配筛选 `$script:ConfigModel.Weapons`。
- 筛选仅重新呈现 `WeaponList`，不会改动配置模型或配置文件。
- 若原选中枪械仍在筛选结果中，保留选中并避免重复加载字段；否则选择结果中的第一项；无匹配时清空选中状态。
- 加载、刷新或浏览到新配置目录时，清空搜索词，并重新显示完整枪械列表。

## 边界与错误处理

- 配置尚未加载时，输入搜索不产生列表更新。
- 无匹配项不弹出错误提示，仅显示空列表。
- 现有的选中样式、字段显示、鼠标型号切换、保存及列表滚动行为保持不变。

## 验证

- 输入 `ak` 时显示包含 `AK` 的枪械；大小写不同的输入得到同样结果。
- 清空搜索后恢复完整列表。
- 选择枪械后，输入仍能匹配该枪械的搜索词时选中项保持不变。
- 搜索后切换鼠标型号、保存配置与重新加载配置均正常工作。
