# 自定义标题栏设计

## 目标

将 AMacQ WPF 编辑器从 Windows 原生标题栏切换为与主界面蓝紫主题一致的自定义标题栏，同时保留常见窗口操作和边缘缩放。

## 范围

- 仅修改 `AMacQGuiEditor.ps1`。
- 移除当前 `Set-DarkTitleBar` DWM 主题函数及其调用。
- 不修改配置读取、保存、动画、侧栏或内容区功能。

## 视觉结构

- 窗口使用 `WindowStyle="None"`。
- 在主布局顶部放置约 38px 高的自定义标题栏。
- 标题栏背景复用主界面蓝紫渐变：`#26345E` 至 `#182243`；底部使用现有紫蓝色细边界。
- 左侧显示 `AMacQ Configuration Editor`，使用现有浅色文字。
- 右侧依次为最小化、最大化/还原、关闭按钮。
- 常规控制按钮悬停使用蓝色强调色；关闭按钮悬停使用红色背景。
- 最大化时按钮显示还原图标。

## 窗口行为

- 使用 WPF `WindowChrome` 保留窗口边缘缩放和最大化工作区边界处理。
- 标题栏的空白区域可拖动窗口；双击可在最大化和还原间切换。
- 窗口控制按钮设置 `IsHitTestVisibleInChrome="True"`，使点击直接执行最小化、最大化/还原和关闭，不触发拖动。
- 最大化时仍不遮挡 Windows 任务栏。

## 实现

1. 在 XAML 窗口上声明 `WindowChrome` 并设置无原生标题栏。
2. 将根布局改为标题栏行加原有内容行；原有侧栏和内容面板移动到内容行，内部布局不变。
3. 新增标题栏资源样式、按钮模板及鼠标事件处理。
4. 将 `WindowState` 与最大化按钮图标状态保持同步。
5. 删除 DWM P/Invoke 函数和 `SourceInitialized` 调用。

## 验证

- PowerShell 语法解析无错误。
- 启动窗口后可拖动、双击最大化/还原、使用最小化/最大化/关闭按钮，并可从窗口边缘缩放。
- 最大化不遮挡任务栏。
- 现有文件选择、配置编辑和保存流程可正常使用。
