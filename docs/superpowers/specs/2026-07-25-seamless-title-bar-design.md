# 融合式标题栏设计

## 目标

让自定义标题栏视觉上连续延伸到下方的侧栏与内容区，去除标题栏底部分隔线；隐藏标题栏中的最小化和最大化/还原按钮，仅保留关闭按钮。

## 范围

- 仅修改 `AMacQGuiEditor.ps1`。
- 保留现有自定义标题栏、`WindowChrome`、拖动、双击最大化/还原及窗口边缘缩放。
- 不修改配置读取、保存、动画、侧栏和内容区内部功能。

## 视觉结构

- 标题栏取消独立的全宽渐变背景与底部边线。
- 标题栏改为左右两列，列宽与下方主布局一致：左列为 220px，右列占剩余空间。
- 左列背景使用现有 `PurpleSidebarBrush`，与下方 `SidebarPanel` 连续。
- 右列背景使用现有 `PurpleContentBrush`，与下方 `ContentPanel` 连续。
- 标题文本置于左侧区域；右侧区域仅保留关闭按钮。

## 窗口行为

- 删除最小化与最大化/还原按钮，以及对应 PowerShell 控件查找、事件绑定和状态图标同步代码。
- 保留关闭按钮及其红色悬停效果。
- 双击标题栏仍由 `WindowChrome` 的标题区命中测试处理最大化/还原。
- 窗口边缘仍可缩放，最大化时仍不遮挡任务栏。

## 验证

- PowerShell 语法解析无错误。
- 启动后标题栏左右区域分别与下方侧栏、内容区背景连续，且无标题栏底部边线。
- 仅显示关闭按钮；关闭功能正常。
- 标题栏拖动、双击最大化/还原和边缘缩放正常；原有配置编辑流程可正常使用。
