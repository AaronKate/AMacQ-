# AMacQ 自定义标题栏图标设计

## 目标

在自定义 WPF 标题栏中显示与 EXE、窗口、任务栏和 Alt+Tab 一致的绿色 AMacQ 程序图标。

## 布局

标题栏左侧保留现有标题区域，在标题文字前增加一个 `Image`。

- 名称：`TitleBarIcon`
- 尺寸：20 × 20 像素
- 左边距：12 像素
- 图标与标题文本间距：8 像素
- 标题栏总高度：保持 38 像素

图标和标题文本置于横向容器中，右侧最小化与关闭按钮的位置、尺寸和交互保持不变。标题栏的空白区域仍可用于拖动窗口。

## 图标来源

窗口创建后继续调用现有 `Set-WindowIcon`：打包 EXE 时从 EXE 内嵌图标提取，直接运行 PowerShell 脚本时从 `assets\AMacQ.ico` 回退加载。

随后将 `$window.Icon` 的同一 `ImageSource` 同步到 `TitleBarIcon.Source`。标题栏不自行读取文件，也不增加新的运行时依赖，因此两个启动模式均显示与窗口/EXE 一致的图标。

## 验证

- 静态测试确认标题栏 XAML 具有 `TitleBarIcon`，且其尺寸为 20 × 20。
- 静态测试确认 `Set-WindowIcon` 后将窗口图标赋给 `TitleBarIcon.Source`。
- 现有标题栏 XAML 解析测试继续通过。
- 重新构建 EXE 并启动，人工确认绿色图标位于标题栏标题文本之前，最小化与关闭按钮正常工作。

## 非目标

- 不改变标题栏高度、窗口拖动、最小化或关闭逻辑。
- 不改变配置文件读取、编辑或保存行为。
- 不引入新的图标资源或外部运行时文件。
