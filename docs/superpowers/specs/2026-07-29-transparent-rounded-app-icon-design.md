# 透明圆角应用图标设计

**日期：** 2026-07-29  
**状态：** 已确认，待实施

## 目标

用用户提供的 `C:\Users\79294\OneDrive\桌面\87c0b374-0033-4f8c-8353-99b11c1507ea.png` 替换 AMacQ 配置编辑器的应用图标，并消除图标画布四角的黑色区域。

生成的图标在 Windows 任务栏、资源管理器、窗口标题栏和 Alt+Tab 中应使用同一套多尺寸图标资源。圆角边界沿用原图现有轮廓，不扩大或缩小圆角。

## 范围

- 将提供的 PNG 纳入项目的 `assets/`，作为应用图标源文件。
- 基于现有圆角方形轮廓制作透明 Alpha 蒙版，使轮廓外四角的像素完全透明。
- 保留圆角轮廓内的霓虹边缘、发光、电路背景及三角闪电标志。
- 使用现有图标转换流程生成兼容 ps2exe 的多尺寸 ICO：16、20、24、32、40、48、64、128、256 像素。
- 使用现有发布脚本重建 EXE，使 ICO 资源嵌入可执行文件。

## 非目标

- 不为小尺寸图标设计另一套简化图形。
- 不改变应用的窗口图标加载逻辑或发布架构。
- 不修改应用功能、界面和主题。

## 处理流程

1. 将用户提供的 PNG 复制到项目图标源路径。
2. 用图像处理脚本以原图圆角边界生成 Alpha 蒙版；轮廓外四角 Alpha 设为 0，轮廓内图像保留。
3. 检查生成 PNG 的四角透明度以及边缘是否保留原始视觉轮廓。
4. 运行既有 `tools/Convert-Icon.ps1`，为 ICO 生成各目标尺寸的 32 位 DIB 图标帧。
5. 运行 `Build-Release.ps1`，将 ICO 通过 ps2exe 嵌入新 EXE。
6. 检查 ICO 和 EXE 的图标资源是否包含预期的尺寸与 Alpha 通道；运行新 EXE 进行手动视觉检查。

## 验收标准

- 透明 PNG 的四个角像素 Alpha 值为 0。
- 透明处理后的圆角形状与原图已有圆角轮廓一致。
- ICO 包含 16 至 256 像素的既有九个尺寸。
- 发布 EXE 含有该 ICO 的完整嵌入图标组。
- 在 Windows 任务栏中，新启动/重新固定的 EXE 不显示黑色四角块，且应用标志可辨识。

## 风险与处理

Windows 可能缓存旧 EXE 或任务栏固定项的图标。验证时必须从新构建的 EXE 启动；若仍显示旧图标，则取消固定旧项，再对新 EXE 重新固定后复测。这不是资源生成失败的判据。
