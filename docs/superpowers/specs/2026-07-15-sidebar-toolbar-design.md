# 侧栏顶部工具栏与自适应武器列表设计

## 目标

精简 AMacQ 配置编辑器侧栏：将目录操作置于标题右侧，删除不再需要的配置分组与目录信息，并让武器列表占满侧栏剩余空间。

## 界面调整

- 顶部使用一行布局：左侧为“AMacQ”，右侧依次为“刷新”和“浏览...”。
- 删除鼠标型号上方的“配置”分组标题。
- 完整删除“配置文件夹”分组，包括标题、路径／未找到提示，以及原来的按钮位置。
- 侧栏只保留三个纵向区域：顶部工具栏、鼠标型号、武器列表。
- 将“武器”区域紧接在鼠标型号下方，使用剩余可用高度。
- 移除武器列表固定的 `300` 高度；列表框随窗口高度自动拉伸和收缩。

## 实现边界

修改 `AMacQGuiEditor.ps1` 中的嵌入式 XAML 与武器列表初始化：

1. 将侧栏行定义由四行改为三行，并删除原配置文件夹的 `Grid.Row="2"` 容器。
2. 将武器区域调整为新第三行（`Grid.Row="2"`），令外层容器可在星号行内拉伸，且列表框通过该容器占用剩余高度。
3. 删除 `$weaponList.Height = 300`；保留滚动条可见性设置。
4. 保留刷新、浏览、配置加载、错误提示、窗口标题、武器选择及保存逻辑。

## 验证

- 顶部显示“AMacQ”，右侧显示“刷新”“浏览...”。
- 侧栏不显示“配置”“配置文件夹”、目录路径或未找到目录消息。
- 武器标题和列表紧接在鼠标型号下方；列表框随窗口大小改变而自适应高度。
- 列表仍可滚动。
- “刷新”“浏览...”功能，以及加载、武器选择和保存流程保持可用。
