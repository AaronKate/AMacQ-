# 罗技游戏鼠标键位预设设计

## 目标

为 AMacQ 配置编辑器增加鼠标型号选择。用户选择型号后，按键面板只展示该型号适合用作宏触发的侧键；保存时仍向 `sorinkg.lua` 写入对应的数字。

## 支持的型号与键位

| 型号 | 可选侧键（Lua 数值） |
|---|---|
| 通用双侧键鼠标 | 左侧后退键 (4)、左侧前进键 (5) |
| G102 | 左侧后退键 (4)、左侧前进键 (5) |
| G304 / G305 | 左侧后退键 (4)、左侧前进键 (5) |
| G Pro Wireless（GPW） | 左侧后退键 (4)、左侧前进键 (5)、右侧后退键 (7)、右侧前进键 (8) |
| G Pro X Superlight（GPX） | 左侧后退键 (4)、左侧前进键 (5) |
| G402 | 左侧后退键 (4)、左侧前进键 (5) |
| G502 Hero | 左侧后退键 (4)、左侧前进键 (5) |
| G502 X | 左侧后退键 (4)、左侧前进键 (5) |

不提供左键、右键、滚轮中键、滚轮方向、DPI/灵敏度切换/狙击键等默认功能键。G502 系列额外拇指区域按键暂不预设，避免将功能键错误映射成宏键。

## 界面与交互

- 在顶部文件夹路径下方增加“鼠标型号”下拉框，默认选择“通用双侧键鼠标”。
- 鼠标型号切换后，按键面板的三个下拉框刷新为该型号的可用侧键，不自动保存。
- Lua 中已有的数值如果不属于当前型号预设，显示“当前配置(数字)”。该选项仅用于保留显示，不会在用户未修改字段时被静默改写。
- 灵敏度面板与鼠标型号选择无关。
- 点击保存时，按键下拉框按所选项的数值写回 `sorinkg.lua`。

## 数据结构

在 PowerShell 脚本中使用 `$script:MouseProfiles` 哈希表，将型号名称映射到键位对象数组。每个对象包含 `Text` 和 `Num`。

## 验证

- 验证默认预设、普通双侧键型号以及 GPW 都能正确填充下拉框。
- 验证 GPW 的 7、8 可选择并写入 Lua。
- 验证切换型号不写入任何 Lua 文件。
- 验证旧配置的未知数字显示为“当前配置(数字)”并不会自动丢失。
