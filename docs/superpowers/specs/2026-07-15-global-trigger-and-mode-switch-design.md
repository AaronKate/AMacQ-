# 右侧全局触发与灵敏度切换设置设计

## 目标

在右侧内容区提供 `sorinkg.lua` 的全局触发方式和灵敏度切换键配置，使用户可以在编辑器中查看和保存 `press` 与 `modeswitch`，而不影响按武器保存的现有字段。

## 界面布局

在右侧标题区域中，将“武器设置”保留为区域标签；在当前“武器：<名称>”标题下方新增一个“全局设置”卡片，位于“配置详情”和武器专属字段之前。

卡片包含两个下拉框：

| 标签 | 可见选项 | `sorinkg.lua` 值 |
| --- | --- | --- |
| 触发方式 | 鼠标左键 | `press=1` |
| 触发方式 | 按住右键 + 鼠标左键 | `press=3` |
| 灵敏度切换键 | Scroll Lock | `modeswitch = "scrolllock"` |
| 灵敏度切换键 | Caps Lock | `modeswitch = "capslock"` |
| 灵敏度切换键 | Num Lock | `modeswitch = "numlock"` |

它们始终显示，不随武器列表选择变化。

## 数据与保存

- 加载有效配置目录后，从已读取的 `sorinkg.lua` 内容解析 `press` 和 `modeswitch`，并选择对应下拉项。
- 若任一项缺失或值不在允许集合中，清空该下拉框，保存按钮保持可用；用户须选择有效值才可保存。
- 点击保存时，先校验两个全局下拉框均有有效选项；再将其值写入当前内存中的 `sorinkg.lua` 内容。
- 现有原子写入、原有武器字段校验、冲突按键清理和保存成功提示保持不变。
- 保存时即使未选中武器，也应能保存这两个全局选项；武器专属字段只在已选择武器时写入。

## 实现边界

在 `AMacQGuiEditor.ps1` 内完成：

1. 添加静态的选项定义，以及读取和替换带引号字符串 Lua 赋值的小型辅助函数。
2. 在右侧 XAML 增加全局设置卡片及命名的两个 `ComboBox` 控件。
3. 在加载配置成功时填充两个全局控件；不把它们放入武器切换处理器。
4. 调整保存处理器，让它在保存全局项后，再按现有逻辑保存已选武器字段。
5. 添加适合单文件脚本的 PowerShell 自检，覆盖 Lua 解析／替换及控件选项映射。

## 验证

- 读取 `press=1` 时显示“鼠标左键”；读取 `press=3` 时显示“按住右键 + 鼠标左键”。
- 读取三个允许的 `modeswitch` 值时显示相应 Lock 键。
- 修改下拉选择后保存，`sorinkg.lua` 中的 `press` 和 `modeswitch` 正确更新，其他 Lua 内容、编码和已有武器保存行为不受影响。
- 无武器选中时，仍能保存有效的全局设置。
- 缺失、空或未知全局值不能被静默覆盖；用户点击保存时得到明确提示。
