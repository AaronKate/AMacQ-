# AMacQ 网页侧栏宽度调整设计

**日期：** 2026-07-25  
**状态：** 待用户审阅

## 目标

解决浏览器版左侧栏标题、刷新按钮与“选择文件…”按钮在同一行被挤压、文字换行的问题。

## 调整内容

- 仅修改 `web/styles.css`。
- 将宽屏 `.app-shell` 的侧栏网格列宽从 `220px` 调整为 `280px`。
- 保持标题、刷新和“选择文件…”按钮当前同一行布局，不调整 HTML 结构、间距规则或按钮文本。
- 保持现有小屏幕 `max-width: 760px` 单列响应式布局不变。

## 验证

- 增加 Pester 静态断言，确认宽屏侧栏宽度为 `280px`，小屏单列媒体查询仍存在。
- 运行现有 Pester、Node 逻辑测试与 JavaScript 语法检查。
- 手工在当前浏览器缩放比例下确认两个按钮不再换行。
