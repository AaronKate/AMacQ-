# AMacQ 本机网页服务与 C 盘文件选择设计

**日期：** 2026-07-25  
**状态：** 待用户审阅

## 目标

为浏览器版编辑器增加一个由 PowerShell 本机服务启动的使用方式，使用户点击“选择文件”时由 Windows 系统文件选择框严格从 `C:\` 打开，并由服务端直接、安全地将编辑结果写回用户选择的两个 Lua 文件。

现有 WPF 编辑器、其启动器，以及直接双击 `web/index.html` 的纯离线下载模式均保留。

## 新增文件

```text
启动AMacQ网页配置界面.vbs    # 双击入口，启动本机服务并自动打开浏览器
AMacQWebEditorServer.ps1     # localhost 服务、系统选文件、读写、自动停止
web/index.html               # 服务状态和退出服务按钮
web/app.js                   # 服务 API 客户端、状态/错误回退
web/styles.css               # 服务状态及退出按钮的磨砂风格
```

## 运行与生命周期

1. 用户双击 `启动AMacQ网页配置界面.vbs`。
2. 启动器在服务可用后，打开本机网页地址。
3. 服务仅监听 `127.0.0.1`，不绑定 `0.0.0.0`、局域网 IP 或公网地址。
4. 网页持续请求服务状态以维持活动并显示连接状态。
5. 用户可点击“退出网页服务”立即停止服务；服务先返回成功响应，再关闭监听器和 PowerShell 进程。
6. 连续 15 分钟没有 API 或静态资源请求时，服务自动退出。
7. 端口被占用或服务启动失败时，启动器显示明确错误，不打开无效页面。

## 文件选择与保存流程

### 文件选择

- 网页服务模式下，点击“选择文件”向本机服务发送 `POST /api/select-files`。
- 服务使用两个 Windows `OpenFileDialog`，依次选择按键和灵敏度 Lua 文件。
- 两个对话框都设定 `InitialDirectory = 'C:\'`，因此每次严格从 C 盘开始。
- 选择同一文件或取消其中任一选择时，不覆盖当前已加载的网页配置；服务返回清晰结果。
- 服务读取两个文件，检测 UTF-8、UTF-8 BOM、UTF-16 LE 和 UTF-16 BE，并将内容、源文件名及可编辑状态返回页面。

### 应用

- 网页沿用现有 Lua 编辑、字段校验、按键冲突清理逻辑，形成两份待保存文本。
- 网页将待保存文本发往 `POST /api/apply`。
- 服务仅针对本会话刚刚由系统选择框选取的两个路径保存；请求不能提供或替换目标路径。
- 服务按文件原始编码，用临时文件后替换的方式原子写回。
- 写入失败时服务返回具体原因，网页保留输入和内存编辑结果。

## HTTP 接口

所有接口只在 `http://127.0.0.1:<port>` 提供，不处理跨网络来源。

- `GET /api/status`：返回服务可用状态、是否已选择文件及剩余空闲时间。
- `POST /api/select-files`：打开两个 C 盘起始的系统选文件框；成功时返回文件内容与元数据，取消或错误时返回可显示信息。
- `POST /api/apply`：接收两份编辑后的文本；服务将其按当前会话的两个已授权路径和编码原子写回。
- `POST /api/shutdown`：返回成功后关闭服务。
- 静态资源仅限 `web/` 下明确允许的文件；URL 不映射任意本机路径。

## 网页模式与回退

- 服务模式连接成功时，显示“本机服务已连接，可直接保存”，并显示“退出网页服务”按钮。
- 无法连接时，网页显示“请通过 `启动AMacQ网页配置界面.vbs` 启动以使用 C 盘文件选择和直接保存”。
- 无服务时，保留现有浏览器文件选择与下载同名文件的纯网页模式。
- WPF 版继续由现有 `.vbs` 启动，不受本功能影响。

## 安全边界

- 服务绑定回环地址 `127.0.0.1`，不接受局域网或公网连接。
- 选择对话框、文件路径、编码和可写目标均由服务端保存；浏览器页面不获得任意路径读写能力。
- 服务只处理用户通过当前会话系统选择框明确选择的两个文件。
- 静态资源路由使用固定白名单，不允许 `..`、绝对路径或任意文件读取。
- 不上传配置、不访问网络、不扫描磁盘、不与游戏进程交互。

## 验证

- Pester 验证：回环监听、两个 `OpenFileDialog` 的 `InitialDirectory = 'C:\'`、原子写入、15 分钟空闲停止、禁止对外监听和静态资源白名单。
- Node 测试保留网页 Lua/编码/冲突清理测试，并增加网页服务连接状态、服务不可用回退和 API 错误显示测试。
- 手工验证：双击新启动器后自动打开浏览器；两次选择均从 C 盘打开；应用直接写回；退出服务立即停止；15 分钟空闲后服务不再响应；直接双击 `web/index.html` 仍能下载保存。
