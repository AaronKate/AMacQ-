# 放大任务栏小尺寸应用图标设计

**日期：** 2026-07-29  
**状态：** 待评审

## 目标

保留现有透明圆角、深色电路背景和青绿色霓虹视觉风格，同时让 Windows 任务栏等 16–32 px 图标中的中心三角闪电标识明显更大、更容易辨认。

## 背景与根因

当前 `assets/AMacQ.ico` 中的九个尺寸帧均从 `assets/AMacQ-source.png` 进行整图等比缩放。完整 256 px 图稿含有细密的背景、电路纹理和外围留白；缩小到 Windows 任务栏选用的 16–32 px 帧后，中心标识占比偏小、背景细节挤压像素预算，因此图标在任务栏中视觉上显小。

运行时窗口图标与 EXE 文件图标均来自同一个 `assets/AMacQ.ico` 内嵌资源。无需修改 `AMacQGuiEditor.ps1` 的图标加载逻辑或 `Build-Release.ps1` 的打包方式。

## 方案

在 ICO 生成链路中引入尺寸分层：

- **小尺寸帧：** 16、20、24、32 px 使用从原始图稿中心区域裁切并放大的版本。
- **常规尺寸帧：** 40、48、64、128、256 px 保持当前完整图稿的整图等比缩放。

小尺寸版本仍保留透明圆角方形、深色背景与青绿色边缘；通过裁切外围低辨识度电路细节，使中心三角闪电标识在 16–32 px 的可见区域中占据更大比例。它不是另一套图标素材，仍完全派生自 `assets/AMacQ-source.png`。

## 实现边界

- 修改 `tools/Convert-Icon.ps1`，使其按图标尺寸选择绘制源矩形：小尺寸使用中心裁切矩形，常规尺寸使用完整源图。
- 保留所有九个 32 位 DIB ICO 帧（16、20、24、32、40、48、64、128、256），以继续兼容 ps2exe。
- 重新生成并提交 `assets/AMacQ.ico`；不提交 `dist/AMacQ配置编辑器.exe`。
- 增强 `tests/IconResource.Tests.ps1`：验证 ICO 帧集合与编码格式不变，并比较小尺寸帧和完整源图的中心标识覆盖范围，确保小尺寸帧确实采用更紧凑的构图。
- 不改变 `assets/AMacQ-source.png`、透明圆角掩码、窗口图标加载机制或 EXE 打包架构。

## 数据流

1. `assets/AMacQ-source.png` 作为唯一图稿输入。
2. `tools/Convert-Icon.ps1` 对小尺寸帧从源图中心区域裁切后缩放；对常规尺寸帧缩放完整源图。
3. 生成的 `assets/AMacQ.ico` 被 `Build-Release.ps1` 通过 ps2exe 的 `-iconFile` 参数嵌入 EXE。
4. Windows 根据实际显示尺寸从 ICO 选择相应帧；任务栏使用小尺寸专用帧，窗口与资源管理器可使用完整构图帧。

## 验收标准

- ICO 仍包含完整的九种尺寸，且每帧保持 32 位非 PNG/DIB 编码。
- 16、20、24、32 px 帧中，中心绿色三角闪电相对于图标画布的覆盖比例显著高于相同尺寸的整图缩放基线。
- 40 px 及以上帧继续呈现当前完整圆角应用图标构图。
- 重新构建的 EXE 可以正常生成并使用 `assets/AMacQ.ico`。
- 任务栏可能缓存已固定应用的旧图标；验证新图标时应从新生成的 EXE 启动，必要时取消固定后重新固定。

## 非目标

- 不为大尺寸场景重绘现有图标。
- 不新增运行时任务栏图标切换机制。
- 不修改窗口标题栏或 EXE 图标加载代码。
