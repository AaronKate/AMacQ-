# macOS 系统设置风格界面设计

## 目标

将 AMacQ 配置编辑器从网页卡片风格调整为接近 macOS System Settings 的原生设置页风格，同时保留现有 Lua 读写、鼠标型号、按键冲突重置与保存行为。

## 布局

- 左侧为独立的浅灰导航栏，显示“武器”分组和武器列表。
- 右侧为设置详情页：顶部显示当前武器名；下方依次显示“鼠标型号”“按键”“灵敏度”设置组。
- 鼠标型号作为一行设置项，左侧标签、右侧下拉框。
- 按键与灵敏度分别为白色连续设置列表：每一行仅用细分割线分隔，而非每个字段单独用灰色卡片包裹。
- 底部仅保留靠右的保存按钮。

## 视觉规范

- 窗口底色：`#F5F5F7`。
- 侧栏底色：`#ECECF0`，右边以 `#D1D1D6` 细线分隔。
- 主标题：20px、`#1D1D1F`、SemiBold。
- 分组标题：12px、`#6E6E73`、SemiBold。
- 设置组：白色，圆角 10px，外层轻微阴影可省略。
- 设置行：最小高度 44px；标签为 13px；相邻行使用 `#E5E5EA` 的 1px 分割线。
- 选中武器：`#007AFF` 蓝色背景、白字、圆角 6px。
- 下拉框和输入框：白色或 `#F5F5F7` 底色、`#C7C7CC` 1px 边框、圆角 6px。
- 保存按钮：蓝色 `#007AFF`、圆角 7px、15px 半粗体、紧凑尺寸。

## 保持不变

- 不改变字段定义、Lua 变量命名、读写编码、原子写入或错误处理。
- 不改变鼠标型号与键位预设规则。
- 不改变武器筛选规则或按类别清除重复键位的保存规则。
- 保持 UTF-8 with BOM，兼容 Windows PowerShell 5.1 中的中文字符串。

## 验证

- 脚本语法解析通过。
- 打开窗口后可选择目录、型号和武器。
- 按键/灵敏度控件仍可加载和保存。
- GPW 显示 4、5、7、8；其他双侧键型号显示 0、4、5。
- 保存成功提示和错误对话框保持可用。
